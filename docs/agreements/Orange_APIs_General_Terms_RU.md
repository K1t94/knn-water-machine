**API-клиент** — веб-сайт (веб-сайты) и/или приложение (приложения), в связи с которыми вы или ваши Бизнес-клиенты используете API Orange.

**Уполномоченный субобработчик** — любое лицо, обрабатывающее Персональные данные по вашему поручению.

**Конфиденциальная информация** — любая непубличная информация, которую сторона письменно или устно обозначает как конфиденциальную либо которая с учётом обстоятельств раскрытия должна считаться конфиденциальной.
